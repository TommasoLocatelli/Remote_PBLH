# Planetary Boundary Layer Height (PBLH) Retrievals with Remote Sensing Data

A lightweight workspace for exploring Planetary Boundary Layer Height (PBLH) retrieval using remote‑sensing instruments such as ceilometers and lidars. The repository contains small utility modules and exploratory scripts for reading, transforming, and visualizing atmospheric data.

Most of the data comes from ACTRIS Cloudnet data portal (https://cloudnet.fmi.fi/search/data).
